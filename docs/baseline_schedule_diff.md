Measurements use fixed, deterministically selected VOC **training** target samples only. Official metrics and artifact ingestion were disabled. The projections are planning estimates, not experimental outcomes; each real run records its actual duration and memory, and its eight-hour deadline remains authoritative.

The official EM sample-wise function uses an unshuffled loader, starts per-sample noise at zero by default, performs `train_step=10` sequential surrogate minibatches, searches noise for every training sample, then evaluates train error before deciding whether to repeat. The production candidate preserves that sequence for the one authorized complete detection-target coverage cycle; it does not repeat after that cycle even if the train-only 0.01 threshold is unmet. The counter row in each `run_spec.json` is authoritative; planned EM batched forward count is 970 for 10 train + 960 noise calls, plus 6,095 train-error forward evaluations (7,065 total); planned backward count is 970. REM/SEM retain their full defender, EOT/stability, attacker-PGD, radius, step-size, loss, and sampling schedules. EntF retains the complete centroid and all 300 Push iterations. The reduction from each method's original classification-training outer horizon to one detection-target coverage cycle is an explicit detection adaptation, not an exact compute-budget reproduction.
